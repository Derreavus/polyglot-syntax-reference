Variables & Assignment

Names bind to objects. There is no declaration; assignment creates the binding. Everything is a reference.

x = 42
x, y = 1, 2                 # tuple unpacking
x, y = y, x                 # swap
a = b = c = 0               # chained

# Augmented assignment
x += 1
x //= 2                     # floor division

# Walrus operator (3.8+)
if (n := len(items)) > 10:
    print(f"Too many: {n}")

# Multiple assignment from iterable
first, *rest, last = [1, 2, 3, 4, 5]

Classes & OOP

class Animal:
    species = "Unknown"             # class attribute

    def __init__(self, name: str):
        self.name = name            # instance attribute

    def speak(self) -> str:
        raise NotImplementedError

    def __repr__(self) -> str:
        return f"Animal({self.name!r})"

class Dog(Animal):
    def speak(self) -> str:
        return f"{self.name} says Woof!"

# Multiple inheritance & MRO

class B(A): ...
class C(A): ...
class D(B, C): ...                  # C3 linearization

Dataclasses & Named Tuples

from dataclasses import dataclass, field

@dataclass(slots=True)              # 3.10+ slots
class Point:
    x: float
    y: float
    label: str = "origin"
    tags: list[str] = field(default_factory=list)

from typing import NamedTuple
class Color(NamedTuple):
    r: int
    g: int
    b: int

from enum import Enum, auto
class Color(Enum):
    RED = auto()
    GREEN = auto()
    BLUE = auto()
★ Default data bag @dataclass for simple field containers. Use frozen=True when values must be hashable/immutable; slots=True when creating many instances.

    ...

T = TypeVar("T")
def first(seq: Sequence[T]) -> T | None:
    return seq[0] if seq else None

# 3.10+ union syntax

    ...

from typing import Protocol
class Drawable(Protocol):
    def draw(self) -> None: ...

from typing import Annotated, Literal, Final, TypedDict
When to use Annotate public APIs and non-obvious locals. Prefer built-in generics (list[int]) over List[int]. Use Protocol for duck typing; TypeVar when input/output types are linked.

★ Defaults list — default sequence · dict — default mapping · set — uniqueness / membership
When to use Prefer list unless you need uniqueness (set), fixed fields (tuple), or key lookup (dict). Use deque for queues / stacks with fast ends.

from contextlib import contextmanager
@contextmanager
def timer():
    start = time.perf_counter()
    yield
    print(time.perf_counter() - start)

Async / Await

import asyncio

async def fetch(url: str) -> str:
    return data

async def main():
    results = await asyncio.gather(
        fetch("a"), fetch("b")
    )

asyncio.run(main())

async with asyncio.TaskGroup() as tg:
    tg.create_task(fetch("a"))
    tg.create_task(fetch("b"))
Common mistake Never call blocking I/O (time.sleep, sync open, heavy CPU work) inside async def — it blocks the event loop. Use asyncio APIs or asyncio.to_thread.
