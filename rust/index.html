Control Flow

No truthiness — conditions must be bool. if is an expression.

let category = if age < 13 { "child" }
else if age < 20 { "teenager" }
else { "adult" };

let mut count = 0;
let result = loop {
    count += 1;
    if count == 3 { continue; }
    if count == 10 { break count * 2; }
};

while condition { ... }
for i in 0..5 { ... }
for i in 0..=5 { ... }
for fruit in &fruits { ... }
for (i, fruit) in fruits.iter().enumerate() { ... }

'outer: for x in 0..5 {
    for y in 0..5 {
        if x * y > 6 { break 'outer; }
    }
}

Ownership & Borrowing

Every value has one owner. Non-Copy assignment moves; the old binding is invalid.

let s1 = String::from("hello");
let s2 = s1;                  // move — s1 invalid
println!("{s2}");

let n1 = 5;                   // i32 is Copy
let n2 = n1;                  // both valid

fn print_len(s: &String) -> usize { s.len() }
print_len(&s);                // borrow, s still valid

fn add_world(s: &mut String) { s.push_str(", world"); }
let mut s = String::from("hello");
add_world(&mut s);

// either one &mut OR any number of & — never both
let s3 = s2.clone();
★ Ownership defaults Prefer borrowing (&T / &mut T) over cloning. Own with T only when you need exclusive ownership.
Need ownership? │ ├─ no → borrow │ ├─ read-only → &T │ └─ mutate → &mut T └─ yes → move T └─ shared ownership? → Arc (or Rc single-threaded)
Common mistake Don't clone() just to silence the borrow checker — prefer a borrow or a redesign.

Error Handling

No exceptions. Recoverable: Result. Unrecoverable: panic!.

fn divide(a: f64, b: f64) -> Result {
    if b == 0.0 { return Err("Cannot divide by zero!".into()); }
    Ok(a / b)
}

match divide(10.0, 0.0) {
    Ok(r) => println!("Result: {r}"),
    Err(e) => println!("{e}"),
}

fn read_number() -> Result> {
    let s = std::fs::read_to_string("num.txt")?;
    let n: i32 = s.trim().parse()?;
    Ok(n)
}

result.unwrap_or(0);
Some(4).map(|n| n * 2);
★ Error handling defaults Result recoverable · Option absence · ? to propagate · Prefer unwrap_or / ok_or over bare unwrap() in libraries.
