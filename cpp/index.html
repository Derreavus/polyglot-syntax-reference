Pointers & Smart Pointers

int* p = nullptr;
p = new int(42);  delete p;

auto up = std::make_unique<int>(42);
auto up2 = std::move(up);

auto sp = std::make_shared<int>(7);
std::weak_ptr<int> wp = sp;
if (auto locked = wp.lock()) { /* use */ }

std::move(x);  std::forward<T>(x);
★ Ownership defaults std::unique_ptr<T> — default exclusive ownership · std::shared_ptr<T> — only when shared ownership is required · std::weak_ptr<T> — non-owning observer
Need ownership? │ ├─ exclusive → unique_ptr<T> └─ shared ├─ owning → shared_ptr<T> └─ observe only → weak_ptr<T>
Common mistake std::move(x) only casts to an rvalue — it does not move by itself. Prefer RAII / smart pointers over raw new/delete.

★ Preferred design Rule of Zero > Rule of Five > Rule of Three. Let the compiler generate special members; manage resources with smart pointers and STL containers.
