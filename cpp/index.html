auto sp = std::make_shared(7);

std::move(x);  std::forward(x);
★ Ownership defaults std::unique_ptr — default exclusive ownership · std::shared_ptr — only when shared ownership is required · std::weak_ptr — non-owning observer
Need ownership? │ ├─ exclusive -> unique_ptr └─ shared ├─ owning -> shared_ptr └─ observe only -> weak_ptr
Common mistake std::move(x) only casts to an rvalue — it does not move by itself. Prefer RAII / smart pointers over raw new/delete.

Selected Design Patterns

// Meyer's singleton (thread-safe since C++11)
class Logger {
  Logger() = default;
public:
  static Logger& instance() {
    static Logger inst;
    return inst;
  }
  Logger(const Logger&) = delete;
};
// Prefer composition; RAII is the core pattern

Gotchas

// Dangling string_view
std::string_view sv = std::string("temp");  // BAD

// Iterator invalidation
auto it = v.begin();
v.push_back(x);   // may invalidate it

// Object slicing
Base b = Derived{};

// std::move is only a cast
auto y = std::move(x);  // move ctor does the work

// Prefer unique_ptr; shared_ptr only for true shared ownership
void f(const std::vector& v);  // avoid accidental copies

// span / string_view do not own data
Common mistake std::move is a cast. Prefer RAII and unique_ptr.
