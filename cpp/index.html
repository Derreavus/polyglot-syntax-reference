Pointers & Smart Pointers

// Raw pointers (prefer smart pointers)
int* p = nullptr;
p = new int(42);
*p = 10;
delete p;
int* arr = new int[5];
delete[] arr;

// unique_ptr — exclusive ownership
auto up = std::make_unique(42);
*up = 99;
auto up2 = std::move(up);       // transfer ownership

// shared_ptr — shared ownership
auto sp = std::make_shared(7);
auto sp2 = sp;                  // ref-count +1

// weak_ptr — non-owning observer
std::weak_ptr wp = sp;
if (auto locked = wp.lock()) {
  // use *locked safely
}

// Move utilities
std::move(x);                   // cast to rvalue
std::forward(x);             // perfect forwarding
RAII: resources are acquired in the constructor and released in the destructor. Prefer this over manual new/delete.

Special Member Functions & Rules

Foo();                          // default ctor
Foo(const Foo&);                // copy ctor
Foo(Foo&&);                     // move ctor
Foo& operator=(const Foo&);     // copy assignment
Foo& operator=(Foo&&);          // move assignment
~Foo();                         // destructor

Foo() = default;                // ask compiler to generate
Foo(const Foo&) = delete;       // disable

Rule of Zero (preferred)

Design classes so the compiler can generate all special members. Use smart pointers and STL containers for resource management.

class Widget {
  std::string name_;
  std::vector data_;
  std::unique_ptr impl_;
  // no user-declared special members needed
};

Rule of Five (C++11+)

If you define any of destructor, copy ctor, copy assign, move ctor, or move assign, define (or delete) all five. Mark move operations noexcept.

Rule of Three (pre-C++11)

If you define any of dtor, copy ctor, copy assign — define all three.

Structs & Classes

struct Point {
  double x, y;
  Point(double x, double y) : x(x), y(y) {}  // member initializer list
};
Point p{1.0, 2.0};          // direct-list initialization

class Animal {
public:
  Animal(std::string n) : name_(std::move(n)) {}
  virtual void speak() const;
  virtual ~Animal() = default;
  const std::string& getName() const { return name_; }
private:
  std::string name_;
};
Prefer member initializer lists over assignment in the constructor body. Initialization order follows declaration order, not the order in the initializer list.

Lambda Expressions

// [capture](params) -> ret { body }
auto add = [](int a, int b) { return a + b; };

// Capture modes
[]          // capture nothing
[=]         // all by value
[&]         // all by reference
[x, &y]     // x by value, y by ref
[this]      // capture this pointer
[*this]     // capture copy of *this (C++17)

// Generic lambda (C++14) / template lambda (C++20)
auto id = [](auto x) { return x; };
auto tmpl = [](T x) { return x; };

// Immediately invoked
int r = [](int x){ return x * 2; }(5);

// Mutable lambda (can modify by-value captures)
auto counter = [n = 0]() mutable { return ++n; };

Selected Design Patterns (modern C++)

// Singleton (Meyer's — thread-safe since C++11)
class Logger {
  Logger() = default;
public:
  static Logger& instance() {
    static Logger inst;
    return inst;
  }
  Logger(const Logger&) = delete;
};

// Factory
std::unique_ptr create(const std::string& type) {
  if (type == "circle") return std::make_unique();
  return std::make_unique();
}
