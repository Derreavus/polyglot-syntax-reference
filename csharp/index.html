Gotchas

// .Result / .Wait() — can deadlock
var x = FetchAsync().Result;   // BAD
var x = await FetchAsync();    // GOOD

// async void — only for event handlers
async Task WorkAsync() { }     // prefer

// LINQ multiple enumeration
var q = items.Where(...);
var list = q.ToList();         // materialize once

// Nullable suppression — use sparingly
string s = maybe!;

// Avoid boxing in hot paths
object o = 42;
Common mistake Prefer await over .Result/.Wait(). Materialize LINQ with ToList() when enumerating more than once.
